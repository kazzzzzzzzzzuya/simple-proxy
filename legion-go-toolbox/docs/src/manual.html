1Before you start

Legion Go Toolbox is a Decky Loader plugin. It puts the hardware settings Lenovo's Windows app (Legion Space) offers, plus a few extras, into the Quick Access menu of SteamOS. Everything is arranged in six tabs.

Three promises

  • Nothing changes until you switch it on. A fresh install leaves power, fan, lights, buttons and battery exactly as they were. The one exception is the controller type Steam sees, which defaults to a Steam Deck controller so Steam offers gyro (see chapter 9).
  • Every change is checked. After writing a setting the plugin reads it back. If the hardware did not accept it you see a Problem line with the reason instead of a switch that looks on but does nothing.
  • Settings stay applied. They are applied again at start-up, after sleep, when a controller reconnects, and when something else (Steam, another tool, the firmware) changes them back - also while the menu is closed.

What you need

ItemDetails
DeviceLenovo Legion Go (model 83E1). Legion Go 2 and Legion Go S are recognised for the parts known to be identical (power limits, charge limit, power light); everything else stays off on those.
SystemSteamOS with Decky Loader installed.
For the fan curve onlyThe acpi_call kernel module (see chapter 6). Everything else works on a stock SteamOS.

2Installing, updating and removing

Install

  1. Install Decky Loader if you do not have it yet.
  2. If Legion Go Gyro is installed, uninstall it first. Its tuning and calibration are copied over automatically the first time Legion Go Toolbox starts.
  3. Copy legion-go-toolbox.zip onto the Legion Go (Downloads is fine).
  4. In Gaming Mode open the Quick Access menu … → Decky (plug icon) → gear icon → General → turn on Developer mode.
  5. In the same settings open Developer → Install plugin from ZIP file → choose the zip.
  6. Open Legion Go Toolbox from the Decky list.

Update

Install the new zip the same way. Decky replaces the old version; your settings are kept and carried forward automatically (for example, version 2.2 moves an untouched controller type to the new Steam Deck default and adds the default swap layout).

Remove

Uninstall it from Decky's plugin list. Before that, switch off Manage power, Custom fan curve and Swap menu buttons if you want the firmware and SteamOS defaults back straight away - the plugin hands these back to the firmware when they are switched off. Lights, remapping and the charge mode are stored in the hardware and stay as last set.

Reading the screens

  • "… is not available" - the device or SteamOS cannot do this. The text underneath names the reason, and where there is a way to get it, says how.
  • Problem (orange) - the last change did not take effect; the text is what the hardware or system reported.
  • Now - what the hardware is actually doing at this moment, read from the device, not what was requested.

Changes are saved as you make them; there is no Save button.

4Home and battery

Overview

Five rows - Power, Fan, Lights, Buttons, Gyro - each show a one-line summary, for example Custom · 12 W · auto · 60 fps. If a module has a problem, its row shows that instead. Select a row to open its tab.

Battery

Shows the charge level and whether it is charging.

Limit charge to 80 %

Turns on the battery's Long Life mode: charging stops at about 80 %. Worth it if the Legion Go spends a lot of time on the charger. The setting is stored in the firmware and survives reboots; turn it off before a long trip to get a full charge.

About

Reset hardware settings returns Power, Fan, Lights, Battery and Controls to their defaults (all off, Steam Deck controller, default swap layout). It does not touch the gyro's calibration and tuning - those have their own reset in the Gyro tab's advanced options.

5Power

First: open Steam's Performance menu and turn off its TDP limit. If both set the power limit they keep overwriting each other.

Manage power

Hands power control to the plugin. The Now line shows the firmware's actual mode and limit. When you switch Manage power off again, the device is put back into the firmware's Balanced mode.

Power mode

ModeWhat happens
Custom (set the watts)You choose the TDP with a slider, within the range the firmware allows. Needed for Auto TDP and for a custom fan curve.
Quiet / Balanced / PerformanceThe firmware's own modes, the same as Legion Space's. The firmware picks limits and fan curve itself.

Auto TDP for a frame rate

You choose a frame rate; the plugin keeps the power as low as possible while still reaching it. Lower power means a cooler, quieter device and longer battery life.

Setting it up

  1. Power mode: Custom.
  2. Turn on Auto TDP for a frame rate.
  3. Choose a Target frame rate (30, 40, 45, 50, 60, 72, 90, 120 or 144 fps).
  4. Set Maximum TDP - the most it may use - and Minimum TDP - the least it may use.
  5. Set a frame limit at the same number, in the game or in Steam's Performance menu. Without a limit the game simply runs as fast as it can and Auto TDP brings the power down until it reaches the target.

How it decides

SituationWhat Auto TDP does
Frame rate below 90 % of the targetAdds 3 W at once
Frame rate between 90 and 97 % of the targetAdds 1 W
Target held for 6 secondsTries 1 W less
That lower setting cannot hold the targetGoes straight back and leaves that setting alone for 45 seconds - longer each time it fails again, up to 10 minutes. This is what makes it settle instead of bouncing.
Just after a changeIgnores 2.5 seconds of readings while the game adjusts
Menu, loading screen, paused gameKeeps the last setting
No game runningUses your Maximum TDP

Status line

ShowsMeaning
at the lowest power that holds the targetSettled - this is the result you want
target held – trying less powerTesting one watt lower
below target – adding powerThe game needs more power right now
at your maximumThe target needs more than your Maximum TDP allows: raise the maximum or lower the target
at your minimumThe game is light; it reaches the target at your Minimum TDP
waiting for the game to draw framesNo frame rate to measure (menu, paused, not in Gaming Mode)

Separate settings per game

With this on, the profile you edit belongs to the game that is running, and is used whenever that game runs. Games without their own profile use the default one. Use the default for this game deletes the game's profile.

CPU boost

Turning boost off keeps the processor at its base clock. It runs cooler and quieter and often costs only a few frames, especially together with a frame limit.

6Fan

Requirement. The Legion Go only accepts a fan curve through a Lenovo firmware call, and Linux can make that call only with the acpi_call kernel module. SteamOS does not include it, and this plugin deliberately does not install kernel modules (that means modifying the read-only system after every SteamOS update). If the module is present - for example installed with Legion Center's Install Fan Support, or on Bazzite - the curve editor appears by itself. Without it the fan follows the firmware's own curve, which is safe.

Custom fan curve

The firmware keeps control of the fan and of overheating protection; the plugin only changes the curve it follows. The firmware uses a custom curve only in the Custom power mode. If the Power tab has a firmware mode selected, the Fan tab says Not in use right now.

Presets

Fan level per temperature (°C). The firmware's scale goes up to 115.

Pick a preset, or move the ten At … °C sliders yourself (the preset then shows Custom). The small graph shows the curve and, as a dashed line, the current temperature.

Safety limits

  • No point can be set below Lenovo's own minimum for the Legion Go - the Silent row above. Handheld Daemon enforces the same limit.
  • The curve always rises with temperature: raising a point lifts the points after it, lowering a point lowers the ones before it.
  • Saved curves from older versions are raised to this minimum automatically.

Full speed

Runs the fan at maximum, ignoring the curve.

Per game and on charger

Two switches let the fan setting depend on what you are doing:

  • Separate settings per game - a game can have its own setting.
  • Separate settings on charger - one setting on battery, another while plugged in.

With both on there are up to four kinds of setting. The plugin uses the most specific one that exists:

OrderSettingExample
1This game, on the chargerElden Ring plugged in: full speed
2This gameElden Ring on battery: Balanced
3All games, on the chargerAnything else plugged in: Cool
4All gamesAnything else on battery: Silent

It switches by itself when a game starts or closes and within two seconds of plugging in or unplugging.

Making a setting

  1. Get into the situation you want to set up - start the game, and plug in or unplug.
  2. Open the Fan tab. The heading names what you are editing, for example ELDEN RING · on charger. Until you change something it says Using the general setting and which one.
  3. Change the preset, the curve or full speed. From then on that case has its own setting.

Use the general setting here removes the setting you are looking at. Saved fan settings lists every setting with its preset; selecting one removes it.

Why a setting can "turn itself off" - and what the plugin does

The firmware throws away full speed and the custom curve whenever the power mode changes - no matter whether Steam, another tool, Auto TDP or a manual change caused it. The fan then quietly falls back to the stock curve and temperatures climb.

The plugin therefore reads both back from the firmware every 5 seconds, and one second after each of its own power changes, and puts them back when they are gone. When this has happened the Fan tab shows a Kept on line, for example The firmware dropped the fan setting 3 times (last just now); the plugin put it back.

The rings around both sticks. Until you change something here the plugin leaves them as they are; the first change takes control.

The setting is stored in the controllers and sent again whenever they reconnect.

Power-button light

  • Power light - on or off.
  • Off while sleeping - switches the light off when the Legion Go goes to sleep, so it does not glow in a dark room, and back on when it wakes. If you keep the light off anyway, it stays off.

The swap is a small profile loaded into InputPlumber (SteamOS's controller layer) on top of the active one, so the other mappings stay. If InputPlumber restarts, the plugin loads it again within a few seconds. Switching it off restores the previous profile.

Remap back buttons

Gives Y1, Y2 (left controller), Y3, M2 and M3 (right controller) a different function, using Lenovo's own remapping stored in the controllers.

Can become
No action · A · B · X · Y · LB · RB · LT · RT · View · Menu · D-pad up / down / left / right · Left or right stick click · Left or right stick up / down / left / right
Note. Steam also sees the back buttons as extra buttons. In games where you use this remapping, leave them unassigned in Steam Input, otherwise a press does both. Switching remapping off sets all five back to No action in the controllers.

Touchpad

Switches the touchpad on the right controller off (or on again), for example if your palm keeps touching it.

9Gyro

The Legion Go has three motion sensors: one in each detachable controller and one in the tablet. The Gyro tab uses them in two separate ways.

Gyro in Steam games

Any game, through Steam Input. Uses the tablet's sensor, so it works with the controllers attached - like a Steam Deck.

Gyro for emulators

Dolphin, Ryujinx, Eden, Cemu and others. Each controller's own sensor, so detached controllers work like Wii Remotes or Joy-Cons.

Gyro in Steam games

Steam offers gyro settings only for controllers that have a gyro. On its own, InputPlumber presents the Legion Go as an Xbox controller, which has none. The plugin therefore presents it as a Steam Deck controller by default.

TypeResult
Steam Deck controller (default)Steam's full gyro options; A/B/X/Y lettering like Xbox
Xbox controller (no gyro)No gyro in Steam; what InputPlumber does without this plugin
DualSense / DualSense EdgeGyro; PlayStation symbols in Steam's menus and in games with their own PlayStation support

A different type for one game

While a game is running, a second list with the game's name appears. Choose a type there and it is remembered for that game: the plugin switches to it whenever the game starts and back to the all-games type when it closes. Same as all games removes the game's own choice; so does selecting the game under Games with their own type.

Note. Switching type reconnects the virtual controller, so Steam may briefly show a controller notification as a game starts.

Button symbols

Most games show Xbox symbols whatever type you pick, because Steam Input hands every game an Xbox-style controller. Games with their own PlayStation support may switch to PlayStation symbols when Steam sees a DualSense; most of them have a button-prompt option in their own settings. Steam's own menus and the controller-settings screen always show the type you picked. The Steam Deck type keeps A/B/X/Y lettering, which makes it the best all-round choice.

Setting up gyro in a game

  1. Pick the type before starting the game - changing it reconnects the controller once.
  2. In the game press the Steam button → Controller settings → Gyro and set it up like on a Steam Deck (for example As mouse or As joystick, enabled while touching the right stick).
Layouts per controller type. Steam stores controller layouts separately for each controller type. After switching type, a game may start with that type's default layout.

Gyro for emulators

The plugin runs a motion server in the DSU / CemuHook format on 127.0.0.1, port 26760. Add it once in each emulator.

SlotDeviceUse it for
1Left controllerNunchuk, left Joy-Con, player 2's remote
2Right controllerWii Remote, right Joy-Con
0Whole handheldGyro aiming with the controllers attached (right controller's sensor, else left, else the tablet)

Calibrate once

Press Calibrate and leave the controllers alone for a few seconds - on a table is best. It finishes as soon as it sees a calm second; if the sensors never get perfectly quiet it uses the calmest second it saw. After that, drift is removed automatically whenever a controller rests.

Dolphin - Wii Sports and other Wii games

  1. Controllers → Alternate Input Sources → enable DSU Client → add server 127.0.0.1, port 26760.
  2. Wii Remote 1 → Emulated Wii Remote → Configure.
  3. Open the Motion Input tab, choose the device DSUClient/2/… (right controller) and press Default.
  4. Map the buttons on the other tabs - from the same device or from your normal gamepad.
  5. For a Nunchuk, set the extension's motion to DSUClient/1/…. For two players, give the second remote slot 1.

Hold the controller like a remote: buttons up, the top edge pointing at the screen.

Switch emulators - Switch Sports and other motion games

Ryujinx / Ryubing

Settings → Input → configure the player → Motion → enable, tick Use CemuHook compatible motion, host 127.0.0.1, port 26760, Controller Slot 1. Leave Mirror Input off and set Right JoyCon Slot 2.

Eden / Citron / other yuzu forks

Configure → Controls → Advanced → Motion/Touch → Configure → add 127.0.0.1:26760. On the player page click Motion 1 and shake the left controller, then Motion 2 and shake the right one.

10Troubleshooting

SymptomWhat to do
A feature says "not available"The text under it gives the reason. Most often: no acpi_call (fan), not in Gaming Mode (Auto TDP), or InputPlumber not running (buttons, Steam gyro).
TDP keeps jumping backTurn off Steam's own TDP limit (Performance menu) and remove other TDP plugins.
Auto TDP stays "at your maximum"The game cannot reach the target within your Maximum TDP. Raise the maximum or lower the target.
Auto TDP says "waiting for the game to draw frames"No game is in focus, it is paused, or you are in Desktop Mode.
Fan full speed or curve switches itself offThe firmware drops them when the power mode changes. The plugin restores them within about 5 seconds; the Fan tab's Kept on line shows when it did.
No fan curve editorThe acpi_call module is missing (chapter 6).
Stick lights or remapping: "controllers not found"Wake the controllers by pressing a button, then change the setting again.
Menu buttons back to normalInputPlumber restarted; the swap is re-applied within a few seconds.
No gyro option in Steam's controller settingsGyro tab → the type for All games (or for that game) must not be Xbox controller. Restart the game after changing it.
PlayStation symbols in a gameThe game supports PlayStation controllers natively. Use its button-prompt setting, or give that game the Steam Deck type.
Emulator gets no motionCheck the server address and slot; the Gyro tab shows "1 emulator connected" once it works. tools/dsu_monitor.py prints the live data without an emulator.
"Port 26760 is already used"Another motion server is running (EmuDeck can install one). Stop it, or pick another port here and in the emulator.
Motion driftsLay the controllers down and press Calibrate.
An axis moves the wrong wayGyro → Advanced options → that slot → Tuning → Invert.

Logs for a bug report are in ~/homebrew/logs/Legion Go Toolbox/.
